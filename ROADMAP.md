# Nova — Public Roadmap

This roadmap is intentionally proof-first. It separates what Nova is building from what still needs validation and avoids presenting planned work as completed product.

## Now — prove continuity is useful

- Recruit serious early users / design partners for long-running workflows.
- Measure whether persistent context reduces repeated setup and lost decisions.
- Test whether provenance and contradiction tracking improve decision consistency.
- Tighten the public product walkthrough around real user problems.
- Expand evaluation around failure modes, uncertainty, and human review gates.
- Keep the financial/options proving ground human-in-the-loop.

## Next — turn the architecture into a repeatable product experience

- Make project memory, source tracking, and unresolved-question handling easier to inspect.
- Improve connected-tool orchestration around a single user objective.
- Add stronger evaluation for conflicting evidence and stale information.
- Build clearer domain-specific workspaces and handoffs between specialist workflows.
- Improve product analytics so behavior, activation, and conversion can be measured instead of guessed.

## Later — broaden beyond the first proving ground

If the continuity thesis survives real-user testing, Nova can expand the same architecture into additional knowledge-work domains where context loss, tool fragmentation, and accountability matter.

The sequence matters: **validate the compounding context layer first, then widen the market.**

## What is deliberately not on the roadmap

- Autonomous trading.
- Guaranteed financial performance.
- Growth claims before real usage exists.
- Publishing private infrastructure, credentials, or proprietary operational details.

## Current public proof points

- Persistent knowledge architecture: **defined**
- Financial/options decision-support framework: **built**
- Public product / founder surface: **live**
- Source-aware outreach and lead funnel: **live**
- Measured real-user validation: **next**

Nova remains in active development. Roadmap items may change as evidence improves.
